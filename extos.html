extOS

Linux terminal in Chrome. extOS opens a lightweight Alpine Linux system in a Chrome extension tab for command-line work, SSH, and network troubleshooting.
Built for practical terminal work

extOS runs locally in the browser using v86. The first public version does not include a hosted relay service; networking is available when you run or choose an extOS relay yourself.

  • Full-tab Linux terminal experience.
  • Autosaved virtual machine state.
  • Localhost relay support for VM networking.
  • Useful tools for developers and system administrators.
extOS stores VM state and settings locally in Chrome. See the extOS Privacy Policy for Chrome Web Store disclosure details.
